# ماتريكس — خطط المعارض

بوابة عربية خاصة لاستعراض مقترحي التعاون والتواصل لـAGRI وHVAC-R. لكل معرض محتواه وأدلته وهويته، ضمن نفس مشروع Sites ونفس إعداد الوصول الخاص.

## الصفحات

- `/`: اختيار المعرض من شعار HVAC-R أو AGRI.
- `/agri/`: خطة AGRI الحالية، بهويتها الخضراء ومحتواها المحفوظ.
- `/hvacr/`: خطة HVAC-R، بهويتها الزرقاء وأقسامها العشرة وخطة نوفمبر 2026 حتى مايو 2027.
- الروابط القديمة `/#intro` و`/#review` و`/#idea` و`/#plan` و`/#content` و`/#together` تنتقل إلى القسم المقابل في `/agri/`.
- داخل كل خطة رابط «اختيار المعرض» للرجوع للبوابة. المسارات مستقلة وتعمل مباشرة، مع الرجوع والتقدم في المتصفح.

## التشغيل

موقع HTML/CSS/JavaScript بلا خطوة بناء أو تبعيات تشغيل خارجية. جميع الخطوط والشعارات والأدلة محلية. للتشغيل من جذر المستودع:

```sh
python -m http.server 8080 --directory dist
```

افتح `http://localhost:8080/`. يُفضّل الخادم المحلي لاختبار الانتقال بين المسارات بدل فتح ملف منفرد.

## تنظيم الملفات

- `dist/index.html` و`portal.css` و`portal.js`: البوابة وإعادة توجيه روابط AGRI القديمة.
- `dist/agri/`: صفحة AGRI وسكربتها، مع استخدام `dist/style.css` وأصولها الأصلية.
- `dist/hvacr/`: صفحة HVAC-R وسكربت تبويباتها وأدلتها وملف هويتها.
- `dist/shared.css` و`experience.js`: نظام العرض والحركة والتصفح والطباعة لخطة HVAC-R، والخط والأساس البصري للبوابة.
- `dist/assets/`: خطوط ثمانية Sans والشعارات الأصلية وأصول AGRI.
- `.openai/hosting.json`: معرّف مشروع Sites المحفوظ ومسار النشر `dist`.

## المحتوى والأصول

اعتمد HVAC-R على ملف `Matrix_HVACR_Website_Content_Brief.docx` الذي قدّمه صاحب المشروع، وعلى نظام ألوانه وشعاره المرفقين. يحتوي العرض على عشرة أقسام وسبعة شهور وست أفكار وست فرص تطوير وأربع صور أدلة. استُخرجت الصور من Word وفق أوصافها E01–E04 وعلاقات الملف؛ لم تُفترض المطابقة من ترتيب أسماء الصور. يحافظ كل دليل على تاريخ الرصد وحد الفحص ومصدره.

نصوص العميل وتفاصيلها فقط موجودة في الصفحات؛ تعليمات التنفيذ والملاحق التشغيلية وملفات المصدر غير منشورة ضمن `dist`. لم نجرِ مراجعة جديدة للحسابات. الاستراتيجية الأصلية ذات 21 صفحة مذكورة في البريف لكنها لم تُرفق كملف مستقل. لا تُستخدم صورة الحساب كدليل على نص منشور غير ظاهر فيها.

بيانات البرنامج والمشاركين وحقوق الرعاية وB2B وخدمات المشترين والموعد التفصيلي ليست وعودًا معتمدة. تظل تغطية أثناء المعرض وما بعده إطارًا مقترحًا، ولا توجد أرقام أداء أو شركات افتراضية أو نماذج تسجيل أو حجز داخل العرض. أمثلة التسجيل والأرقام الموجودة في PDF الألوان لم تُنقل كمحتوى للعرض.

حُفظ محتوى `main` الخاص بـAGRI كما هو؛ التعديلات عليه تخص مسار الملفات ورابط الرجوع للبوابة. لا تُستخدم صوره وأدلته أو شهوره كبديل لأصول HVAC-R. شعار ماتريكس الرأسي الأصلي يُعرض في البار بلا خلفية داكنة، وبجواره شعار المعرض المفتوح. شعار HVAC-R المقدم 200 × 100 بكسل؛ يظهر بحجم محدود مع الحفاظ على نسبه.

خط ثمانية Sans محلي بأوزان عادي ومتوسط وعريض، بلا Serif. مرجع ملفات الخط: https://github.com/eltawalbeh/thmanyah-fonts-public، والمرجع الرسمي: https://font.thmanyah.com/.

## التصفح والحركة والطباعة

انتقالات الأقسام كصفحات تصعد وتغطي السابقة، بعد إتاحة استعراض محتوى القسم الطويل كاملًا. تتوقف الأقسام المغطاة عن استقبال التركيز وتُعاد عند الرجوع بالسكرول. يعاد حساب ارتفاعاتها عند تغير المحتوى والخطوط والشاشة. تفضيل النظام لتقليل الحركة يعيد التدفق العادي؛ لا توجد أزرار وضع عرض أو تقليل حركة.

الشهور السبعة موجودة في HTML وتعمل بتبويبات عربية تدعم الأسهم وHome وEnd. يمكن فتح شهر أو دليل برابط مباشر مثل `/hvacr/#MAY27` أو `/hvacr/#E03`، مع إظهار التبويب أو التفاصيل المطلوبة. تكبير الأدلة يستخدم نافذة أصلية ويعيد التركيز إلى زر الفتح عند الإغلاق. عند الطباعة تظهر جميع الشهور والتفاصيل، ثم تُستعاد حالة التصفح بعد الطباعة.

## التحقق المنفذ

- فحص صياغة JavaScript وCSS، وكل الأصول المحلية والروابط الداخلية ومعرّفات ARIA في الصفحات الثلاث.
- مقارنة نص المحتوى الأصلي لـAGRI والتحقق من تبويباته والتكبير ومسارات الصور بعد النقل.
- فحص مسارات إعادة توجيه الروابط القديمة، واكتمال أقسام HVAC-R والشهور والأفكار والأدلة وعزل محتوى الخطتين.
- اختبارات DOM لتغيير الشهور والتنقل بالكيبورد والروابط المباشرة للدليل والشهر وقائمة الأقسام وعودة التركيز بعد التكبير.
- اختبارات DOM لعرض الشهور والتفاصيل عند الطباعة واستعادتها، وحسابات التثبيت والرجوع بالسكرول والاستجابة لتقليل الحركة.

هذه فحوص وظيفية وبنيوية، وليست فحصًا بصريًا في متصفح. أداة المتصفح غير متاحة في بيئة التنفيذ الحالية؛ لم يُعتمد فحص بصري جديد للموبايل أو الكمبيوتر أو معاينة الطباعة النهائية. توجد تنسيقات للشاشات الصغيرة، لكن صحة مظهرها النهائي تحتاج معاينة متصفح.

## النشر والوصول

تُرفع نفس حالة المصدر إلى مستودع GitHub الذي اختاره المستخدم وإلى مصدر Sites، ويُجهّز أرشيف النشر من الالتزام نفسه. لا يُستخدم GitHub Pages. يبقى الوصول الخاص محفوظًا؛ وجود معرّف المشروع وحده لا يثبت نجاح النشر، ونتيجة أداة Sites هي المرجع للرابط والحالة.

المستودع الذي اختاره المستخدم عام. لا يحتوي ملفات اعتماد أو بيانات أداء داخلية أو نسخ البريف وملاحقه. العرض المنشور يحافظ على جمهوره الخاص في Sites.
