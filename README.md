# ماتريكس × أجري إكسبو

عرض عربي تفاعلي لمقترح التعاون قبل المعرض. يبدأ بالمراجعة، ثم الفكرة، ثم خطة نوفمبر وديسمبر ويناير، وينتهي بنطاق التعاون وخطوة خطة المحتوى.

## التشغيل

افتح `dist/index.html` مباشرة في Chrome أو Edge. جميع موارد العرض الأساسية محلية. لا توجد مكتبات خارجية أو خطوة بناء أو جمع بيانات زوار.

للتشغيل عبر خادم محلي: `python -m http.server 8080 --directory dist`.

## المحتوى

- أمثلة من مراجعة ١٩ أكتوبر ٢٠٢٦؛ روابط الأمثلة متاحة في بطاقاتها. أزيلت نافذة المصادر وتفاصيل حدود المراجعة من واجهة العرض حسب طلب صاحب المشروع.
- لا توجد نتائج أداء مفترضة أو أهداف لأعداد العارضين والرعاة.
- تجهيزات أرض المعرض تظهر في يناير وقت حدوثها قرب الافتتاح.
- التعاقدات مسؤولية إدارة المعرض.
- أمثلة الشكل المقترح للمحتوى موضحة باعتبارها تصوّرات.

## الأصول والنشر

خط Thmanyah Sans وحده مستخدم في كامل الموقع بأوزان عادي ومتوسط وعريض، وجميع ملفاته محلية. أزيل خط Serif. مصدر ملفات الخط: https://github.com/eltawalbeh/thmanyah-fonts-public، والمرجع الرسمي: https://font.thmanyah.com/.

الشعاران الأصليان من ملف Desktop.zip الذي أرسله صاحب المشروع: `matrix-logo.png` و`agri-logo.png`. استُخدما كما هما، بلا إعادة رسم أو تغيير نسب أو ألوان. يظهر شعار ماتريكس الفاتح على خلفية داكنة. حُذفت البدائل المؤقتة وملاحظاتها.

الافتتاحية تجمع الشعارين في تكوين عائم بسيط مع استجابة خفيفة للمؤشر، بلا دوائر أو مدارات أو علامة ×. شريط التنقل يعرض ماتريكس فقط. النسخة الرأسية الجديدة وصلت كمعاينة في المحادثة ولم يتوفر ملفها؛ شريط التنقل يستخدم النسخة الأفقية الأصلية الموجودة في Desktop.zip مؤقتًا، وباقي مواضع الشعارات لم تتغير.

تظهر الأقسام كصفحات تصعد فوق السابقة مع التمرير باستخدام sticky. يحسب كل قسم موضع تثبيته حسب ارتفاعه وارتفاع الشاشة والبار: القسم الطويل يمر كامل محتواه قبل تثبيت نهايته، ثم يغطيه القسم التالي في ترتيب طبقات متزايد. تتحرك الزخارف الداخلية بقوة أقل لتبقى القراءة واضحة. علامات تنقل مستقلة في التدفق تحفظ الوصول لبداية كل قسم حتى بعد تثبيته. الأقسام المغطاة تتوقف عن استقبال التركيز والتفاعل وتُعاد عند الرجوع بالسكرول. يُعاد حساب الأبعاد مع تغير المحتوى والخطوط وحجم الشاشة. تعطيل JavaScript أو تفضيل النظام تقليل الحركة يعيدان التدفق العادي، والطباعة تعرض الأقسام متتابعة بلا تراكب.

حُذفت نافذة المصادر وزرها وكتلة تفاصيل حدود المراجعة. حُذف وضع العرض وزر تقليل الحركة من الإصدار السابق. لا توجد تبعيات تشغيل خارجية أو اعتراض لحركة عجلة التمرير أو اللمس.

يُستخدم مشروع Sites المحفوظ في `.openai/hosting.json` للنشر الخاص. لا يُستخدم GitHub Pages. نتيجة أداة النشر هي المرجع لحالة النشر والرابط. المستودع الذي اختاره صاحب المشروع عام؛ لا يحتوي ملفات اعتماد أو بيانات أداء داخلية. مصدر Sites يستقبل الالتزام نفسه الذي بُني منه أرشيف النشر.

## التحقق

في تحديث ٢٠ أكتوبر ٢٠٢٦: اجتاز JavaScript فحص الصياغة. اجتازت اختبارات DOM الأصول المحلية والروابط والتبويبات والتكبير وقائمة الموبايل. اختُبرت حسابات تثبيت الأقسام الطويلة والقصيرة، وتعطيل التركيز في الصفحات المغطاة واستعادته عند عكس التمرير، والتنقل عبر علامات التدفق، والعودة للتدفق العادي عند تفعيل تقليل الحركة في النظام. فُحص حذف عناصر الهيرو والمصادر المطلوبة، وبقاء الشعارات الأصلية خارج البار.

هذه اختبارات وظيفية في DOM، وليست فحصًا بصريًا في متصفح. أداة المتصفح غير متاحة في بيئة هذه المراجعة، لذلك لم يُعتمد اختبار بصري جديد على الكمبيوتر أو الموبايل.

## الوصول والحركة

اتجاه عربي من اليمين لليسار، تنقل بالتبويب ولوحة المفاتيح، تكبير اللقطات، وحركة تراعي تفضيل النظام لتقليل الحركة. لا يستخدم التصميم ظلالًا خلف النصوص.
