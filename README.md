# ماتريكس × أجري إكسبو

عرض عربي تفاعلي لمقترح التعاون قبل المعرض. يبدأ بالمراجعة، ثم الفكرة، ثم خطة نوفمبر وديسمبر ويناير، وينتهي بنطاق التعاون وخطوة خطة المحتوى.

## التشغيل

افتح `dist/index.html` مباشرة في Chrome أو Edge. جميع موارد العرض الأساسية محلية. لا توجد مكتبات خارجية أو خطوة بناء أو جمع بيانات زوار.

للتشغيل عبر خادم محلي: `python -m http.server 8080 --directory dist`.

## المحتوى

- أمثلة حقيقية من مراجعة ١٩ أكتوبر ٢٠٢٦، مع توضيح حدود العينة.
- لا توجد نتائج أداء مفترضة أو أهداف لأعداد العارضين والرعاة.
- تجهيزات أرض المعرض تظهر في يناير وقت حدوثها قرب الافتتاح.
- التعاقدات مسؤولية إدارة المعرض.
- أمثلة الشكل المقترح للمحتوى موضحة باعتبارها تصوّرات.

## الأصول والنشر

خطوط Thmanyah Sans (عادي ومتوسط وعريض) وThmanyah Serif Display (متوسط) مضمنة محليًا، بدل خط Cairo المؤقت. مصدر ملفات الويب: https://github.com/eltawalbeh/thmanyah-fonts-public، والمرجع الرسمي: https://font.thmanyah.com/.

`dist/assets/matrix-mark.svg` ما زال تمثيلًا نصيًا مؤقتًا، وليس الشعار الأصلي؛ ملف الشعار المرفق في المحادثة السابقة غير متاح في هذه البيئة، وتنزيله من موقع MATRIX محجوب. الملاحظة مذكورة داخل نافذة المصادر. شعار Agri الموجود مستخرج من لقطة رسمية موثّقة.

يُستخدم مشروع Sites المحفوظ في `.openai/hosting.json` للنشر الخاص. لا يُستخدم GitHub Pages لأن العرض مطلوب للاستخدام الخاص. وجود المعرّف وحده لا يثبت نجاح النشر؛ نتيجة أداة النشر هي المرجع لحالته ورابطه.

المستودع الذي اختاره صاحب المشروع عام؛ لا يحتوي ملفات اعتماد أو بيانات أداء داخلية. مصدر Sites مستقل عن مستودع GitHub، ويجب أن يستقبل نفس الالتزام الذي بُني منه أرشيف النشر.

## التحقق

في تحديث ٢٠ أكتوبر ٢٠٢٦: اجتاز JavaScript فحص الصياغة، واجتازت اختبارات DOM الأصول المحلية والروابط الداخلية، تبديل أمثلة المراجعة الأربعة، الشهور الثلاثة، الفئات، التنقل بين التبويبات بلوحة المفاتيح، التكبير والإغلاق، قائمة الموبايل، وضع العرض، الخطوة التالية وتقليل الحركة. فُحصت ترويسات ملفات WOFF2.

هذه اختبارات وظيفية في DOM، وليست فحصًا بصريًا في متصفح. أداة المتصفح غير متاحة في بيئة هذه المراجعة، لذلك لم يُعتمد اختبار بصري جديد على الكمبيوتر أو الموبايل.

## الوصول والحركة

اتجاه عربي من اليمين لليسار، تنقل بالتبويب ولوحة المفاتيح، تكبير اللقطات، وضع عرض، وخيار لتقليل الحركة. لا يستخدم التصميم ظلالًا خلف النصوص.
