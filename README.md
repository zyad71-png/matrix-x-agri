# ماتريكس × أجري إكسبو

عرض عربي تفاعلي لمقترح التعاون قبل المعرض. يبدأ بالمراجعة، ثم الفكرة، ثم خطة نوفمبر وديسمبر ويناير، وينتهي بنطاق التعاون وخطوة خطة المحتوى.

## التشغيل

افتح `dist/index.html` مباشرة في Chrome أو Edge. جميع موارد العرض الأساسية محلية. لا توجد مكتبات خارجية أو خطوة بناء أو جمع بيانات زوار.

للتشغيل عبر خادم محلي: `python -m http.server 8080 --directory dist`.

## المحتوى

- أمثلة حقيقية من مراجعة ١٩ أكتوبر ٢٠٢٦، مع توضيح حدود العينة.
- لا توجد نتائج أداء مفترضة أو أهداف لأعداد العارضين والرعاة.
- تجهيزات أرض المعرض تظهر في يناير وقت حدوثها قرب الافتتاح.
- التعاقدات مسؤولية إدارة المعرض.
- أمثلة الشكل المقترح للمحتوى موضحة باعتبارها تصوّرات.

## الأصول وحالة النشر

تعذّر تنزيل شعار MATRIX الأصلي وحزمة خطوط Thmanyah في بيئة التنفيذ الحالية. `dist/assets/matrix-mark.svg` بديل نصي مؤقت صريح، وليس نسخة من الشعار الأصلي. خط Cairo بديل مؤقت، وشعار Agri الموجود مستخرج من لقطة رسمية موثّقة. يلزم استبدال هذه الأصول بالملفات الأصلية قبل اعتبار الهوية نهائية.

النشر الخاص على Sites لم يكتمل بسبب تعذّر الاتصال بخادم المصدر. معرف المشروع محفوظ في `.openai/hosting.json`، ولا يعني وجوده أن الموقع منشور. لا يُستخدم GitHub Pages لأن العرض مطلوب للاستخدام الخاص.

يحتوي هذا المستودع على كود العرض. المستودع الذي اختاره صاحب المشروع عام، لذلك لا تضع فيه بيانات دخول أو بيانات أداء داخلية أو معلومات شخصية.

## الوصول والحركة

اتجاه عربي من اليمين لليسار، تنقل بالتبويب ولوحة المفاتيح، تكبير اللقطات، وضع عرض، وخيار لتقليل الحركة. لا يستخدم التصميم ظلالًا خلف النصوص.
